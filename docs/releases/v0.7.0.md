# DeskBuddy 0.7.0

## Windows 支持

- 适配 Windows 10/11 x64：透明置顶窗口、原生拖动（逐帧跟随、工作区钳制、支持多显示器）、悬停反应、四向视线跟随、提示音（WinMM）、文件管理器定位、NSIS 安装包（currentUser 模式，中英文）。
- 配置与会话数据位于 `%USERPROFILE%\.config\deskbuddy\`；ZCode 会话标题依赖 PATH 中的 `sqlite3`（未安装时回退任务摘要）。
- 应用内更新支持 Windows（NSIS setup.exe + minisign 签名）。

## 角色体系

- 移除内置预置角色；内置角色改为动态扫描打包资源目录 `assets/pets/<角色id>/`，放置角色包即可随应用分发。
- 没有任何角色时应用空窗待命并提示添加，不再回退预置角色。
- GIF 拆帧改为应用内置 Rust 解码器，组装不再依赖 bash/Swift。

## 行为与修复

- 待机轮播默认不再包含"爬动"（会改变窗口位置）；可在 behavior.json 的 weights 中手动加回。
- 修复 Windows 上外部角色加载失败（`ext:` 路径分隔符）。
- 修复"打开角色文件夹"打开错误目录（混合分隔符路径 explorer 无法解析）。
- 修复拖动无法跨越显示器边界（钳制基准改为光标所在屏工作区）。

## 发布

- 更新签名公钥更换为本仓库维护者密钥；0.6.0 及更早版本客户端需手动安装本版本一次，之后可继续在应用内更新。
