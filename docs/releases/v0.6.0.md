# DeskBuddy 0.6.0

- 设置 → 关于支持检查更新、查看更新说明、下载并安装，以及安装后重启。
- 导入角色包时只保留运行所需的图片和连续动作帧，自动跳过制作记录和预览文件。
- 修复图片角色与动画角色互相切换时画面未更新、动画模式残留的问题。
- 修复待机随机动作不触发，以及视线跟随打断启动打招呼的问题。
- 更新应用 Logo，设置栏目使用“陪伴”等文案。

目前提供 macOS Apple Silicon 安装包。0.5.x 版本需手动安装本版本一次，之后可在应用内更新。

角色与配置保存在本机，更新不会主动删除这些数据。当前安装包未经 Apple 公证；macOS 可能要求首次通过访达右键打开。
