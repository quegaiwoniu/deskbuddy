# 技术决策

## Tauri 与 PixiJS

Rust 后端负责本地事件接入、配置、文件和原生窗口能力；TypeScript/PixiJS 负责角色渲染与界面。平台相关行为集中在 Rust 模块中。当前支持范围以 README 为准。

## 本地事件接入

使用回环 HTTP 接口和同一二进制中的 CLI，便于接入能执行脚本的编码工具。会话日志增量读取补充工具回调未提供的信息。应用不依赖运行时云端模型来播放角色动作。

## 角色包

角色资源使用 `pet.json` 描述，可加载独立帧、雪碧图或静态图片。`x-actions` 等扩展字段提供动作播放配置。界面使用“陪伴”和“角色”，文件格式及 CLI 保留 `pet` 命名以兼容现有数据。

## 配置驱动

行为、事件与心情反应通过本地 JSON 配置管理，支持设置页修改和文件热重载。

## 素材与许可

源码与项目许可见根目录 LICENSE。外部导入的角色素材需要单独检查其授权。私人素材、会话日志和访问令牌不应进入公开仓库或发布包。
